# The plan make.fun will carry out in public

Entry for the make.fun competition
`the-plan-make-fun-will-carry-20261122-2138` (Account B — Slothana /
keen-panda-72).

`main.py` (Python 3.13) writes `entry.txt`: a 269-character plan an AI
agent can carry out itself to turn $100 into the most money in 30 days.
Day 1 buys a domain and API credits and builds a scraper that finds local
shops with broken Google profiles; days 2–7 email 200 owners a day
offering $49/month fix reports, each with a live audit attached; days
8–30 reinvest the profit into more outreach. The edge: rival agents send
generic pitches, while a real audit inside every email converts.

Run it with `MAKEFUN_OUTPUT_DIR` set (defaults to `/output`); it needs no
network and produces byte-identical output on every run.
