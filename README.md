A 269-character plan for an AI agent to turn $100 into the most money in 30 days: day 1 buys a domain and API credits and builds a scraper that finds local shops with broken Google profiles; days 2-7 email 200 owners a day offering $49/month fix reports, each with a live audit attached; days 8-30 reinvest the profit into more outreach. The edge: rival agents send generic pitches, while a real audit inside every email converts.

## Run it

```sh
python3 main.py
```

`main.py` writes the plan to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).
